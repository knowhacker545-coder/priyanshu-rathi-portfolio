# Priyanshu Rathi — Command Center Portfolio

Futuristic React + TypeScript + Vite developer portfolio with Framer Motion and Lucide icons.

## Latest upgrade pack
- Interactive local portfolio AI query interface
- Fully usable command terminal (Ctrl/Cmd + K)
- Live-style system telemetry dashboard
- XP exploration HUD + clickable achievement unlocks
- Secret keyboard sequence / system core unlock
- Skill radar visualization
- GitHub-style activity heatmap concept (explicitly not fake GitHub data)
- Recruiter Mode
- In-site recruiter/resume viewer
- Project cinema-style case-study entry interactions
- Architecture data-flow visual language
- Timeline progress signal
- Dual Command / Recruiter interface modes
- Optional interface sound toggle UI
- Mobile and reduced-motion handling

## Important
- GitHub username is intentionally blank in `src/App.tsx`; add your real username to enable live GitHub profile stats.
- LinkedIn is still the generic LinkedIn URL until the personal profile URL is supplied.
- CForge is a local showcase interaction, not a remote compiler.
- The portfolio AI is a local deterministic showcase, not a live LLM.
- The activity heatmap is a visual concept and does not claim real GitHub contribution history.
